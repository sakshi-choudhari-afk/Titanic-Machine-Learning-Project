# Titanic Survival Prediction using Machine Learning

## Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning techniques.

The project uses the Titanic dataset and builds a classification model using Python and Scikit-learn.

## Problem Statement
The objective is to predict passenger survival based on features such as age, gender, passenger class, fare, family members, and embarkation port.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Project Workflow
1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Train-Test Split
6. Model Building
7. Model Evaluation
8. Survival Prediction

## Machine Learning
- Problem Type: Supervised Learning
- Task: Binary Classification
- Target Variable: Survived
- Model: As implemented in the notebook

## Project Files
- `Titanic_ML_Project.ipynb` – Machine Learning notebook
- `titanic_model.pkl` – Saved trained model
- `app.py` – Streamlit application
- `requirements.txt` – Project dependencies

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Conclusion
This project demonstrates how Machine Learning can be used to solve a real-world classification problem and predict passenger survival based on available data.
